# Saylat — Android

Пакет: `com.baddysays.saylat` · minSdk **26** · targetSdk **35**

## Сборка

Откройте эту папку в Android Studio — Gradle Wrapper подтянется автоматически.

```text
Build → Make Project
Run → app
```

## Прокси по умолчанию

| Среда | URL |
|-------|-----|
| Эмулятор | `http://10.0.2.2:8787` |
| Устройство | `http://<LAN-IP>:8787` |
| Ваш VPS | `http://ВАШ_IP:8787` (в приложении при первом запуске) |

**Поиск:** на главном экране строка внизу. По умолчанию **SearXNG** (open source, JSON). В настройках — движок, инстанс SearX, прокси, умная вёрстка.

Настройки в приложении (иконка шестерёнки).
