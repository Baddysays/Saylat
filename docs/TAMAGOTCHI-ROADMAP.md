# Saylat Tamagotchi — карта улучшений

Цель: **пиксельный питомец**, ради которого хочется открывать Saylat (не только ждать загрузку страницы).

Интерактивная версия карты: `canvases/saylat-tamagotchi-roadmap.canvas.tsx` в проекте Cursor.

---

## Северная звезда

Питомец — маскот бренда и ежедневная привычка: короткий уход, долгая привязанность (имя, стадия, streak), мягкая связь с чтением в медленной сети. Визуал: **пиксель-арт**, не векторный «blob».

---

## Что не так сейчас (кратко)

| Проблема | Почему мешает удержанию |
|----------|-------------------------|
| Не пиксельный рендер | Не совпадает с запросом и с образом «ретро / Saylat» |
| `stop()` / `isReady` не связаны с UI | Сломанный цикл «загрузка → игра → готово» |
| Питомец только при `loading` + «Статистика загрузки» | Большинство не видит игру; gate может быть без питомца |
| Жёсткий decay за 2 с | Питомец «умирает», пока пользователь ждёт 2G — злость на приложение |
| Нет сохранения между визитами | Нет причины вернуться «ради питомца» |
| DEAD без смысла | Нет game over / восстановления / эволюции |

## Дорожная карта

### P0 — Починить цикл (спринт 1, малый объём)

- Единая машина состояний: `Hidden → Waiting10s → Active → PageReady → Dismissed`
- `stop()` при `loading = false`; overlay «Готово» только если был `Active`
- Питомец не зависит от переключателя «Статистика загрузки»
- Сброс gate при новой загрузке / смене URL
- Связать кнопку overlay с контроллером (`onReadyClicked`)

### P1 — Пиксель-ядро (средний объём)

- Спрайт-лист 32×32 (или 16×16): idle, eat, happy, sad, sleep, sick, tap
- Рендер с `FilterQuality.None` / nearest-neighbor, палитра 8–16 цветов
- Пиксельные полоски HP, пузырь речи в стиле 9-patch
- Опционально: короткие 8-bit звуки (выкл. в настройках)
- Тот же маскот на главной и в лендинге

### P2 — Настоящий тамагочи (большой объём)

- Профиль в DataStore: имя, возраст, стадия, streak, последний визит
- Мягкий decay **между** визитами (часы), не за 30 с ожидания
- Эволюция 3–5 стадий (яйцо → салатик → …) за чтение / streak
- Ежедневный подарок при входе; реплика «скучал» после 24–48 ч
- Награда за действия Saylat: статья прочитана, офлайн-кэш → салат / XP
- Опциональная мини-игра при долгой загрузке (байты / полосы)

### P3 — Рост (очень большой объём)

- «Дом питомца» на главной (строка + badge «нужен уход»)
- Виджет / ярлык с состоянием питомца
- Скриншот «мой питомец» для шаринга
- Сезонные скины и коллекция (косметика, не блокировка читалки)

---

## Пять столпов «хочется вернуться»

1. **Привязанность** — имя, дневник, стадия; игрок вкладывается.
2. **Награда, не наказание** — 2G уже стресс; питомец утешает, не умирает за одну загрузку.
3. **Петля зашёл → ухаживал → получил** — как классический Tamagotchi, 10–30 с на главной.
4. **Пиксель как ДНК** — отличие от Chrome Dino и Material UI.
5. **Честная связь с Saylat** — XP за чтение, офлайн-кэш кормит, реплики про режим 2G.

## Chrome Dino vs Saylat (целевое)

| | Chrome Dino | Saylat Tamagotchi |
|---|-------------|-------------------|
| Стиль | Пиксель, один герой | Пиксель-маскот + комната / уход |
| Когда | Нет сети | Долгая загрузка + главная + между визитами |
| Память | Нет | Профиль, streak, эволюция |
| Цель | Убить время | Привязанность + мягко вести к читалке |

## Метрики

- Доля пользователей с `home_pet_tap` / неделя
- Streak 3+ дня у включивших tamagotchi
- % отключивших tamagotchi (цель: не раздражает, < ~15% MAU)
- Время на gate «Готово» (страница уже видна)

---

## Чего избегать

- Смерть за одну долгую загрузку
- Gate поверх уже загруженной статьи без контекста
- Векторный «милый» стиль вместо пикселя
- Игра, спрятанная за «Статистика загрузки»
