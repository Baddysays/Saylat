# Личный Saylat — не публичный сервис

## Что имелось в виду под «страницей для людей»

Это **не** «открыть Saylat всему интернету». Имелся в виду простой экран на **вашем** VPS:

- скачать APK;
- скопировать адрес `http://IP:8787` в приложение;
- без Swagger и JSON на главной.

Сервер по-прежнему **ваш**: кто не знает IP и не прошёл файрвол — не зайдёт.

## Что убрано из репозитория

- Жёстко прошитый IP в коде Android и в документации.
- Идея «общего» сервера по умолчанию для всех пользователей.

Адрес задаётся:

1. при первом запуске приложения, или  
2. в `android/local.properties` → `saylat.server.url` (только у вас на машине), или  
3. в `saylat.deploy.env` → `SAYLAT_DEPLOY_HOST` (только у вас, для деплоя).

## Деплой на ваш VPS

```powershell
# saylat.deploy.env (не коммитить):
# SAYLAT_DEPLOY_HOST=ваш.ip
.\scripts\deploy-saylat-vps.ps1
```

Или:

```powershell
.\scripts\deploy-saylat-vps.ps1 -ServerHost "ваш.ip"
```
