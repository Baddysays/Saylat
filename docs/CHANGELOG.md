# История изменений Saylat

Формат: версия приложения (`versionCode`). APK и OTA: [releases/update.json](../releases/update.json).

## 0.5.40 (49) — текущая

- Тамагочи при долгой загрузке страницы (>10 с): питомец, уход, салатики, «Готово»
- Переключатель в настройках
- Исправлена передача параметров тамагочи в `SettingsSheet`

## 0.5.38 (48)

- Упрощена главная: убраны лишние плитки, «Скрыть» вместо «Снова» для теста сети
- CI: `update.json` обновляется после публикации APK на GitHub
- Исправлено расхождение `versionName` в Gradle и тега релиза (служебный тег `v0.5.39`)

## 0.5.37 (47)

- Исправлен вылет при старте: разрешение `ACCESS_NETWORK_STATE` для мониторинга сети

## 0.5.36 (46)

- Лента «Все ленты»: «Показать ещё», пагинация
- История посещений на главной
- Баннер «нет интернета», офлайн-кэш
- «Поделиться» ссылкой в читалке
- Плейсхолдеры картинок, повтор HTTP-запросов
- Сервер: rate limit с очисткой IP, CORS через env, пагинация `/api/feed`
- Лендинг v3: cookie, privacy, Metrika после согласия
