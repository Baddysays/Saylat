# Saylat: тонкий клиент (плохой интернет)

## Идея

Вся тяжёлая работа — **на сервере**. Телефон получает **структурированный ответ** (карточки / лента / полосы) или **WebView**, загружающий HTML через прокси VPS.

## Классическая четвёрка POST

| # | Метод | Назначение | Сейчас |
|---|--------|------------|--------|
| 1 | `POST /api/open` | Открыть URL / ящик / чат → лента или статья | ✅ |
| 2 | `POST /api/query` | Поиск, фильтр | ✅ веб-поиск |
| 3 | `POST /api/translate` | Перевести текст блоков | ✅ |
| 4 | `POST /api/act` | Ответить (почта, Telegram) | ✅ reply |

## Режимы читалки (Android)

| Режим | Поведение |
|--------|-----------|
| **Экономия** | JSON `/api/open`, layout без фото |
| **Полосы (Opera)** | `/api/render/strips?engine=browser`, ad-block на скриншоте |
| **WebView** | полная страница через прокси |
| **Авто** | медленная сеть → экономия, быстрая → полосы; пусто → WebView |

## Сервисы

| Сервис | Сервер | Android |
|--------|--------|---------|
| Сайты | extract, strips, visual | ✅ |
| Почта IMAP | `open mail`, полное письмо по `mail-FOLDER-uid`, `act reply` | ✅ лента, читалка, ответ |
| Telegram | Telethon, `context_id` чата, `act reply` | ✅ диалоги, сообщения, ответ |
| ВК / Дзен | ленты | частично |

## Офлайн

На устройстве кэш последних статей и полос; список на главном экране.
