Привет! Это место для вопросов по Saylat, идей и настройке **личного сервера**.

## Быстрый старт

1. **APK** — [последний релиз](https://github.com/Baddysays/Saylat/releases/latest) или ваш сервер: `http://ВАШ_IP:8787/app/download/saylat.apk`
2. **Сервер** — скрипт `install-saylat-server.sh`, подробнее в [docs/LICHNYI-SERVER.md](https://github.com/Baddysays/Saylat/blob/main/docs/LICHNYI-SERVER.md)
3. В приложении: **Настройки → адрес сервера** (`http://IP:8787`)
