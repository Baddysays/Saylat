# Системные требования Saylat

Версия документа: 0.1.0 · Проект: [Saylat](../README.md) · Автор: **baddysays**

Два уровня: **минимальные** (работает, но медленнее / с ограничениями) и **рекомендуемые** (комфортная разработка и эксплуатация).

---

## 1. Клиент (Android)

Приложение `com.baddysays.saylat` — нативный UI, данные с прокси-сервера Saylat.

| Параметр | Минимум | Рекомендуется |
|----------|---------|---------------|
| Android | **8.0** (API **26**) | **10+** (API **29+**) |
| ОЗУ устройства | **1 ГБ** свободно | **2+ ГБ** свободно |
| Постоянная память | **80 МБ** под установку + кэш | **256 МБ+** под кэш статей (когда появится) |
| Экран | от **320×480** dp | **720p+** |
| Google Play Services | не обязательны | — |
| Сеть на устройстве | **GPRS/EDGE/2G** (целевой сценарий) | **3G/4G/Wi‑Fi** для разработки и тестов |
| Доступ к прокси | HTTP к вашему серверу (в т.ч. `cleartext` в debug) | HTTPS к прод-серверу |

**Минимальный сценарий:** телефон на 2G, прокси доступен по IP/домену, страница без тяжёлых SPA — JSON обычно **&lt; 100 КБ** после сжатия.

**Ограничения на минимуме:** долгая загрузка (30–120 с на страницу), до **6** картинок на статью, без офлайн-кэша (в текущей версии).

## 2. Сервер (Saylat Proxy)

Python-сервис: извлечение текста, санитизация, сжатие JPEG, отдача JSON.

| Параметр | Минимум | Рекомендуется |
|----------|---------|---------------|
| ОС | Linux **x86_64** / Windows **10+** / macOS **12+** | Linux **Ubuntu 22.04+** / **Debian 12+** |
| Python | **3.11** | **3.12** |
| CPU | **1** vCPU | **2+** vCPU |
| ОЗУ | **512 МБ** | **2 ГБ** |
| Диск | **2 ГБ** | **10 ГБ** SSD |
| Сеть (исходящая) | **128 Кбит/с** стабильно | **10+ Мбит/с** |
| Порты | **8787/TCP** (по умолчанию) | **443** за reverse-proxy (nginx/Caddy) |
| Зависимости ОС | для `lxml`: `libxml2`, `libxslt` (на Linux) | те же, из пакетного менеджера |

**Минимальный сценарий:** один процесс `uvicorn`, до **~5** одновременных запросов, страницы до **2 МБ** HTML (лимит в конфиге).

**Рекомендуется для прод:** reverse-proxy, HTTPS, лимит rate-limit, мониторинг, деплой на VPS в доступной инфраструктуре.

## 4. Сеть и целевые условия (2G / ограничения)

| Параметр | Минимум | Рекомендуется |
|----------|---------|---------------|
| Скорость downlink | **~10–50 Кбит/с** (GPRS/EDGE) | **256+ Кбит/с** для отладки |
| RTT | **500–2000 мс** | **&lt; 200 мс** (Wi‑Fi/LAN к прокси) |
| Размер ответа API | ориентир **&lt; 150 КБ** | **&lt; 50 КБ** текстовые статьи |
| Таймаут клиента | 30 с connect / 60 с read | те же; на 2G ожидайте retry в UI позже |
| TLS | не обязателен в dev | **обязателен** в прод |

Прокси **не обходит** операторские белые списки: доступны только те сайты, которые разрешены **на пути сервера → интернет**.

## 5. Переменные окружения сервера

См. [`server/.env.example`](../server/.env.example). Префикс: **`SAYLAT_`**.

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `SAYLAT_HOST` | `0.0.0.0` | bind |
| `SAYLAT_PORT` | `8787` | порт |
| `SAYLAT_IMAGE_MAX_WIDTH` | `480` | ширина JPEG |
| `SAYLAT_MAX_IMAGES` | `6` | картинок на статью |
| `SAYLAT_REQUEST_TIMEOUT_SEC` | `25` | таймаут upstream |

## 7. Что не входит в минимальные требования (пока)

- WebView-режим «полная страница»
- Офлайн-кэш (Room)
- On-device LLM
- Подпись release APK / публикация в RuStore / Play

Эти пункты могут поднять рекомендуемые требования в следующих версиях.
