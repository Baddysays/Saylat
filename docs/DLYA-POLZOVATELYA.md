# 📱 Saylat — личный сервер и телефон

Saylat **не облачный сервис для всех**. Это программа + **ваш** VPS (или домашний ПК): вы поднимаете прокси у себя, ставите APK себе и близким — спокойно и без лишней рекламы в сети.

## 1. Сервер (одна команда на вашем VPS)

```bash
curl -fsSL https://raw.githubusercontent.com/Baddysays/Saylat/main/scripts/install-saylat-server.sh | bash
```

В конце скрипт покажет адрес вида `http://ВАШ_IP:8787/` — **запишите его**, он нужен в телефоне.

### Как не «светить» сервер публично

- В панели VPS / `ufw` **не открывайте 8787 для всего мира**, если не хотите.
- Разрешите доступ только с **вашего IP**, домашней сети или **VPN** (WireGuard, Tailscale).
- Не добавляйте IP в открытый git и не рекламируйте как «публичный Saylat».

Пример (только ваш IP):

```bash
sudo ufw allow from ВАШ_IP to any port 8787 proto tcp
sudo ufw enable
```

## 2. Телефон

1. С **того же VPS** (или из локальной сети) откройте `http://ВАШ_IP:8787/` и скачайте APK.
2. Установите Saylat.
3. При первом запуске вставьте **тот же адрес** (`http://…:8787`).
4. Готово: поиск и сайты идут через ваш сервер.

## 3. Сборка APK только для себя (опционально)

Чтобы не вводить адрес каждый раз на новых сборках, в `android/local.properties` (файл **не в git**):

```properties
saylat.server.url=http://ВАШ_IP:8787
```

См. `android/local.properties.example`.

## Обновление приложения

**APK и обновления — с GitHub**, не с вашего VPS:

- https://github.com/Baddysays/Saylat/releases/latest
- В приложении: **Настройки → Проверить обновление**

Прокси-сервер нужен только для сжатия страниц, не для установки новой версии.
